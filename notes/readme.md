# Конспект занятий по машинному обучению.

`ml-notes.pdf` — единый содержательный конспект на русском языке, в двух колонках.
Пять файлов занятий включаются в `main.typ`; общая вёрстка находится в `style.typ`.
Каждое занятие начинается с новой страницы; пятое занимает три страницы.

| Файл                            | Занятие                                                                      |
| ------------------------------- | ---------------------------------------------------------------------------- |
| `01-ml-tasks.typ`               | 15.09.2026: задачи ML, kNN, признаки, бейзлайны, EDA и KDE.                  |
| `02-linear-regression.typ`      | 22.09.2026: МНК, интерпретация, GD/SGD, ковариация и степени свободы.        |
| `03-logistic-regression.typ`    | 29.09.2026: логит, ММП, кросс-энтропия, odds ratio и калибровка.             |
| `04-regularization.typ`         | 06.10.2026: Ridge, Lasso, ElasticNet, коллинеарность и проксимальные методы. |
| `05-statistical-properties.typ` | 13.10.2026: интервалы, Вальд, Стюдент, HC0–HC3 и модель дисперсии.           |

## Сборка.

Из этой директории:

```sh
typst compile main.typ ml-notes.pdf
```

Используются установленные шрифты PT Serif, PT Sans, STIX Two Math и DejaVu Sans Mono.
Внешних Typst-пакетов нет.

## Источники.

Основой служат пять видео и соответствующие TSV-транскрипты из `~/Downloads/ML`.
Математические записи сверены с кадрами доски и экранов; формулы перенабраны в Typst.
Стандартные уточнения условий, нормировок и численной реализации включены рядом с соответствующими результатами.

## Транскрипт пятого занятия.

Запись от 13.10.2026 «Статистические свойства моделей» в имени файла обозначена как семинар.
TSV лежит рядом с MP4 под тем же именем; столбцы `start` и `end` содержат миллисекунды, `text` — речь.
Автоматический транскрипт содержит ошибки распознавания, особенно в формулах и репликах из аудитории.
В конспекте терминология и математические записи сверены с доской и экраном.

Команда итогового прохода:

```sh
env -u PYTHONPATH -u PYTHONHOME whisper-ctranslate2 \
    "$HOME/Downloads/ML/13-10-2026 Семинар - Никита Волков - Статистические свойства моделей.mp4" \
    --model large-v3 --device cuda --compute_type int8_float16 \
    --language ru --task transcribe --batched False \
    --beam_size 3 --best_of 1 --condition_on_previous_text False \
    --vad_filter True --output_format tsv --output_dir "$HOME/Downloads/ML"
```

`PYTHONPATH` и `PYTHONHOME` очищаются из-за конфликта Python 3.14 проекта с Python 3.13 в установленном Whisper.
На GPU с 4 ГБ памяти проход с пятью кандидатами завершился ошибкой CUDA out of memory.
Итоговый проход использует три луча поиска, одного кандидата при сэмплировании
и отключённую передачу предыдущего текста, чтобы уменьшить повторяющиеся фрагменты.
