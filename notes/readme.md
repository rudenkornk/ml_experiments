# Конспект занятий по машинному обучению.

`ml-notes.pdf` — единый плотный конспект на русском языке, в двух колонках.
Четыре файла занятий включаются в `main.typ`; общая вёрстка находится в `style.typ`.

| Файл | Занятие |
|---|---|
| `01-ml-tasks.typ` | 15.09.2026: задачи ML, kNN, признаки, бейзлайны, EDA и KDE. |
| `02-linear-regression.typ` | 22.09.2026: МНК, интерпретация, GD/SGD, ковариация и степени свободы. |
| `03-logistic-regression.typ` | 29.09.2026: логит, ММП, кросс-энтропия, odds ratio и калибровка. |
| `04-regularization.typ` | 06.10.2026: Ridge, Lasso, ElasticNet, коллинеарность и проксимальные методы. |

## Сборка.

Из этой директории:

```sh
typst compile main.typ ml-notes.pdf
```

Используются установленные шрифты PT Serif, PT Sans, STIX Two Math и DejaVu Sans Mono.
Внешних Typst-пакетов нет.

## Источники.

Основой служат четыре видео и соответствующие TSV-транскрипты из родительской директории.
Математические записи сверены с кадрами доски и экранов; формулы перенабраны в Typst.
Стандартные уточнения условий, нормировок и численной реализации включены рядом с соответствующими результатами.
Опорные временные диапазоны указаны в тексте, точные времена изображений — в подписях.
